# 居家健身 · 本地交互原型

使用现有工具箱的海军蓝、薄荷青和三套浅色主题；仅用于产品交互与数据规则验证，没有修改Android工程。

从仓库根目录运行：

```powershell
node prototype/fitness/serve.mjs
```

打开 [本地预览](http://127.0.0.1:5183)。不需要安装前端依赖；服务仅监听本机回环地址。服务器不会写业务资料，浏览器将演示数据保存在本地存储。

规则测试：

```powershell
node --test prototype/fitness/model.test.mjs prototype/fitness/plan-picker.test.mjs prototype/fitness/experience.test.mjs
```

## 可以走查

- 今日：连续日期轴、休息/未安排、今日部位、连续天数、按状态变化的主操作；继续定位未完成动作，聚焦记组与编号撤销、手动下一动作；历史多组补记及整批撤销，恢复事实可追溯。
- 动作库：首页仅部位/活动分类 → 主练默认/辅助可选、器械/来源筛选与双图列表 → 动作详情；独立全库搜索、收藏与最近练过。16个内容样稿，教学图滑动/鼠标拖动/方向键切换，显示姿势与页码，支持放大和失败重试。
- 计划：四步向导与单日快捷、全入口草稿保护、缺项预览直达修正；第三步按部位展示已选与目标，独立选择页提供每批20条、固定已选及无结果时自建并加入。批量目标默认只填空值；多日总览/批量部位/多日复制、个人单日模板、选中日编辑及归档原安排复制可操作。
- 统计：7/30天及自定义、计划/用途、部位/动作/每日记录、可选实际值与左右覆盖率；筛选范围说明及组成记录→日期→返回统计。
- 管理：器械、主题、必填/选填自建动作和个人图片、JSON备份预检与替换、来源、失败场景；未保存表单退出保护。

默认演示日期为2026-10-23，可在管理中调整。演示目标不是训练剂量建议。查看教学返回、刷新和页签切换不会清空已保存记录；“恢复演示数据/空白初次使用”需明确确认。

## 验证边界

47项规则测试通过（原有22项＋计划选择10项＋体验规则15项）。浏览器已走查记组、教学返回、实际值统计、建计划、归档复制、草稿保持与失败重试、多日批量、模板、统计追溯，以及带1张真实PNG的JSON预检恢复、损坏图片拒绝。此前80条模拟候选的分批和搜索验证继续有效。测试使用localhost独立资料，不覆盖127.0.0.1中的计划/草稿。详细结果见 `docs/居家健身工具/11-原型覆盖与阶段验证记录.md`、`14-体验优化执行与验收记录.md`。

当前标准JSON备份和恢复共用20 MiB UTF-8上限，单张个人图片3 MiB；持久化预留封装空间。浏览器自身存储配额可能更早耗尽，失败会保留旧资料。下载提示只说明已发起下载；原始资料导出是兜底保留路径，不承诺可由当前原型恢复。

原型没有GIF，不会自动计时或识别动作。图片和肌肉映射仍待专业审校；前臂和肩部细分图层有明确缺口。浏览器JSON备份不等于Android ZIP媒体恢复，真实Room、进程中断、APK大小与解码性能尚未验证。

源码：`app.mjs`负责页面/交互；`model.mjs`负责规则与聚合；`plan-picker.mjs`负责候选筛选、分组、选择和批量目标；`experience.mjs`负责入口状态、备份边界、多日批量/模板、补记及恢复事实；`style.css`负责样式；`content/fitness/pilot`负责内容样稿、图像和来源台账。`serve.mjs`只提供本地静态文件，不接收任何外部上传。
