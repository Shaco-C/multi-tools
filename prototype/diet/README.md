# 饮食不适记录 · 交互原型

沿用随身工具箱的浅色背景、海军蓝主卡片、薄荷青色按钮和圆角布局。支持手机与桌面视口。

在仓库根目录执行 `node prototype/diet/serve.mjs`，打开 http://127.0.0.1:5180 。不需要安装依赖。使用 ES 模块，请通过本地服务打开，不要双击 HTML。

只记录出现不适的饮食，不登记正常饮食。新增不适记录时，品牌、食品、类型均从维护好的列表选择；点击入口时自动记下发生时分，进食日期默认昨天。

可体验：品牌和食品集中维护、不适类型维护（默认腹泻）、重命名、停用与重新启用、默认类型切换、一键追加不适与撤销、新建饮食并同时保存首次不适、相关饮食与类型明细、修改饮食信息、修改和删除不适事件、按品牌柱状图、两种统计口径、类型及时间筛选、图表到明细保留筛选。

记录时遇到缺少选项，可进入管理页补齐后继续，原记录草稿与自动发生时间会保留。选择同一食品会提示以前记录的不适次数。管理页的食品选项不代表实际吃过，也不进入历史统计。

旧版原型的已记录不适会迁移到新版结构；没有关联不适的旧饮食不再显示，食品仍保留在维护列表中。名称以 ID 引用，改名不拆分统计，停用不删除历史。

首次打开包含相对今天生成的示例数据。数据仅写入浏览器 localStorage，不会写入 Android 数据库。右上角可重置示例数据。

运行 `node --test prototype/diet/model.test.mjs` 可验证首次事件与追加计数、改名关联、停用保护、分类重复校验、无效记录事务、筛选与旧数据迁移。
