# 电费工具 CSV 导出格式

CSV 用于在 Excel、LibreOffice 或其他表格软件中查看和分析，不用于恢复应用数据。需要迁移或还原时应使用 JSON 备份。

## 编码和行结构

- 文件使用 UTF-8，并在开头写入 BOM，降低 Windows Excel 打开中文时出现乱码的概率。
- 使用逗号分隔、CRLF 换行，所有单元格统一使用双引号包裹。
- 单元格中的双引号按 CSV 规则写成两个双引号；逗号和换行会保留在带引号的单元格内。
- 账单按月份升序，每个月的每一户各占一行，因此同月的总电费、总用量和备注会在各户行重复出现。

## 字段

`账单月份`、`总电费(元)`、`总用量(度)`、`户序号`、`电表标识`、`电表名称`、`是否本人`、`上期读数`、`本期读数`、`本期用量(度)`、`分摊金额(元)`、`备注`、`创建时间(UTC)`、`更新时间(UTC)`。

金额始终输出两位小数，读数保留数据库中的十进制精度，时间输出为 ISO-8601 UTC 格式。

## 安全处理

电表标识、名称、本人标记和备注属于文本字段。如果字段以制表符、回车或换行开头，或者去除前导空格后以 `=`、`+`、`-`、`@` 开头，导出器会在原值前增加英文单引号，避免 Excel 将内容作为公式执行。原始数据不会因此在数据库中发生变化。
