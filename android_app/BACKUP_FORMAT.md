# 电费工具 JSON 备份格式

当前格式版本为 `1`，工具数据版本为 `1`。备份是 UTF-8 JSON 文件，只包含电费工具数据，不包含登录信息、云端标识或其他工具的数据。

备份文件是未加密明文，便于人工检查和跨设备迁移；其中包含电费与电表读数，应由用户自行选择安全位置保管。

## 顶层字段

- `format`：固定为 `pocket-toolbox-backup`。
- `formatVersion`：通用文件格式版本。
- `toolId`：固定为 `electricity`，避免把其他工具的文件错误恢复到电费数据库。
- `schemaVersion`：电费工具备份数据版本。
- `exportedAt`：导出时的 Unix 毫秒时间戳。
- `bills`：按月份升序保存的完整账单数组。

每份账单保存月份、总金额分值、总用量、创建/更新时间、备注，以及全部电表的稳定标识、顺序、名称、本人标记、上下期读数、用量和分摊金额。

数据库自增主键不写入备份；恢复时会重新生成主键。月份和电表稳定标识会保留，因此趋势和下月自动带入不受影响。

## 恢复规则

1. 文件最大 5 MB，最多 1200 个月账单，每月最多 20 户。
2. 必须匹配文件格式、工具 ID 和当前数据版本。
3. 所有月份必须唯一，第一条明细必须是本人电表。
4. 每户用量必须等于本期读数减上期读数，明细用量及金额合计必须与账单一致。
5. 选择文件后只进行解析和预览，不会立即写入。
6. 用户再次确认后，Room 在一个事务中清空当前电费账单并写入备份；任何校验或写入失败都会保留恢复前的数据。

恢复只替换电费工具数据。以后新增的小工具应实现自己的 `BackupContributor`，拥有独立的工具 ID、版本和校验逻辑。
