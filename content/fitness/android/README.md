# Android动作内容包

由`node content/fitness/scripts/build-native-content.mjs`生成：16份可用于内部联调的中文待审样稿，以及876条完整来源资料。11份候选对应只用于关联源资料，不代表动作/照片专业审校通过。原始内容文件保留来源结构，Android在加载时生成稳定的可选记录定义。

Android动作库、分类和计划选择器共提供892个内置条目：16份中文样稿和876个来源动作。来源动作使用`SRC-原始ID`，保留原名、原步骤、原图与来源版本；按原有肌群和类别映射浏览分类。部分样稿与源库存在候选对应，因此892为可选条目数，不代表892种互不重复且完成中文审校的动作。可直接收藏和加入计划，无须逐条复制成个人动作；“全量来源”仍保留原始台账浏览。

来源拉伸和有氧默认按秒，其他默认按次；所有安排在首次记组前均可改为次数/秒数、合计/每侧，并重新填写目标。存在任何完成或撤销历史后，原计量口径锁定。器械未知/other保留为待确认，不归为徒手；默认查看全部器械，器械偏好筛选仍可手动开启。分类映射和记录口径不代替中文教学、器械组合及专业审校，不作为自动推荐或自动计组。

Gradle从已有内容目录同步16份原图/肌肉图，再从固定SHA-256的本地源ZIP提取1746张原图到模块`build/generated/fitnessAssets`，不把重复大图再提交一次Git，不在构建/运行时联网拉取。移动到另一台电脑时需携带`source-archives`中的ZIP；校验值见provenance。生成媒体是构建输出，可以重新构建。

v1.2.0按用户确认发布当前来源库版本，Debug和Release均提供健身及离线素材。产品发布开关与锁定版本见`release.properties`，发布时核对目录版本、sourceRevision和原包SHA-256；内容生成脚本不会覆盖发布配置。

`content.properties`的`releaseApproved=false`、`reviewedCount=0`描述专业教学审校状态，与产品发布开关独立。发布不冒充完成中文教学或专业审校。后续全量中文化和审校按逐项台账推进，不能只手改审核标记。发布验证见[21](../../../docs/居家健身工具/21-v1.2.0正式发布.md)。
