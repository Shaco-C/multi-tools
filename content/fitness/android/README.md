# Android开发内容包

由`node content/fitness/scripts/build-native-content.mjs`生成：16份可用于内部联调的中文待审样稿，以及876条完整来源资料。11份候选对应只用于关联源资料，不代表动作/照片专业审校通过。其余来源的中文、器械和计量仍按全量生产队列整理，不擅自猜测计次。

Android动作库展示中文样稿；“全量来源”可离线检索全部876条原名、原说明和原图。来源资料可以复制为个人动作，由用户明确填写名称、用途、器械与计量；未经整理的英文来源不直接成为系统推荐或自动计次定义。

Gradle从已有内容目录同步16份原图/肌肉图，再从固定SHA-256的本地源ZIP提取1746张原图到模块`build/generated/fitnessAssets`，不把重复大图再提交一次Git，不在构建/运行时联网拉取。移动到另一台电脑时需携带`source-archives`中的ZIP；校验值见provenance。生成媒体是构建输出，可以重新构建。

`content.properties`当前`releaseApproved=false`。debug接入健身和开发素材；release不注册健身入口、不打入待审媒体，保留现有电费/饮食发布能力。全量中文化和审校完成后，正式内容构建应输出统一目录和逐项审核结果，再开启正式内容；开启时release预构建核对数量与状态，不能只手改一个标记冒充内容通过。
