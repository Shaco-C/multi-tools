# OPT-1.2.1-002 每户电费分摊算式

| 项目 | 内容 |
| --- | --- |
| 登记日期 | 2026-11-04 |
| 计划实现版本 | 1.2.1 |
| 所属模块 | 电费分摊 → 月度费用 |
| 优先级 | P2 |
| 当前状态 | 待实现 |

## 使用场景

录入月度总电费和各户的上月、本月电表读数后，在每户费用下方展示代入实际数字的分摊算式。点击保存时，弹出一份完整账单供核对。用户可以直接截取这个弹窗发给对方，让对方在同一张图上看到总金额、各户读数和应付金额的计算过程。

## 展示规则

- 每户用电量按「本月读数 − 上月读数」展示，全部用电量由本次参与分摊的各户用电量相加得出。
- 在每户下方显示「总电费 × 本户用电量 ÷ 全部用电量」，代入数字并标明最终应付金额。建议将用电量、合计和金额分行排版，让单户截图也能读懂。
- 最终金额取本次分摊结果，沿用现有按用量分摊及分币尾差规则。遇到尾差时，算式应区分按比例算出的金额与最终应付金额，让展示金额和保存金额一致。
- 建议在录入结果和已保存账单详情都提供算式，方便当场截图和日后回查。历史账单使用该期的总金额、读数及分摊结果。
- 读数未填完整、校验失败或总用量为零时，跟随现有结果状态展示，避免生成无法计算的算式。

## 保存前确认弹窗

点击「保存」后，先按现有规则校验账单。校验通过后打开「确认月度电费」弹窗，按草图的顺序呈现以下内容。

| 从上到下 | 展示内容 |
| --- | --- |
| 账单摘要 | 账单月份和本期总电费，突出总金额。 |
| 各户读数 | 按户名列出「上期读数」「本期读数」，一户一行。 |
| 分摊明细 | 显示全部用电量，逐户列出读数差、代入数字的分摊算式和最终应付金额。末尾显示各户应付合计。 |
| 操作 | 「确认保存」提交弹窗中核对过的账单。「取消」返回录入页并保留填写内容，可调整后重新预览。 |

弹窗在点击「确认保存」前保持可见，方便核对和截图。两户账单采用紧凑排版，以常用手机竖屏的一张截图容纳金额、读数和算式为设计目标。户数较多或字体放大时，允许明细区滚动并保持底部按钮可用。

### 弹窗内容示例

**确认月度电费 · 2026 年 11 月**

本期总电费 **155.28 元**

| 户别 | 上期读数 | 本期读数 |
| --- | ---: | ---: |
| 第一户 | 5667.3 | 5751.3 |
| 第二户 | 13512.1 | 13695.6 |

全部用电 `84 + 183.5 = 267.5 度`。

- **第一户**用电 `5751.3 − 5667.3 = 84 度`，应付 `155.28 × (84 ÷ 267.5) ≈ 48.76 元`。
- **第二户**用电 `13695.6 − 13512.1 = 183.5 度`，应付 `155.28 × (183.5 ÷ 267.5) ≈ 106.52 元`。

应付合计 `48.76 + 106.52 = 155.28 元`。

**确认保存**　　**取消**

## 两户示例

总电费 **100.00 元**。第一户上月读数 10、本月读数 50。第二户上月读数 20、本月读数 100。

| 户别 | 该户下方展示的计算过程 | 最终应付 |
| --- | --- | --- |
| 第一户 | 本户用电 `50 − 10 = 40 度`。全部用电 `40 + 80 = 120 度`。按比例分摊 `100.00 × 40 ÷ 120 = 33.333… 元`。 | 33.33 元 |
| 第二户 | 本户用电 `100 − 20 = 80 度`。全部用电 `40 + 80 = 120 度`。按比例分摊 `100.00 × 80 ÷ 120 = 66.666… 元`。 | 66.67 元 |

## 验收项

- [ ] 使用上述两户数据，每户均显示对应读数差、全部用电量、代入金额的算式和最终应付金额。
- [ ] 单独截取第二户，仍可看出 `80 ÷ 120` 所表示的用电比例，以及 66.67 元的来源。
- [ ] 修改总金额或任一户读数并重新计算后，受影响的算式与分摊结果同步更新。
- [ ] 有分币尾差时，各户展示金额与保存金额一致，合计等于总电费。
- [ ] 查看已保存的月份时，算式与该期记录对应。在手机窄屏上，长算式可以换行完整显示。
- [ ] 点击保存后先显示确认弹窗。用两户示例在常用手机竖屏核对，单张弹窗截图能读到月份、总金额、两户读数、两户算式及应付合计。
- [ ] 点击取消可继续修改。重新打开时按最新输入展示读数和结果。点击确认保存后，保存的账单与弹窗中的核对内容一致。
- [ ] 账单校验失败时，在录入页面提示对应问题。多户或大字体时，明细可以滚动查看，底部操作始终可用。
