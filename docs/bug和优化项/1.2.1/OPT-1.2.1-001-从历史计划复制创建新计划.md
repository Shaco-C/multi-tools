## 1. 使用场景与目标

用户每周训练安排大体相同，新一周期只需要对上一周期进行微调。如果每次都重新选择日期、部位、动作及训练目标，会产生大量重复操作。

用户示例：已有11月1日至11月7日的计划，结束后准备创建11月8日至11月14日的计划。希望在创建时选择“从历史计划中复制”，选中原计划并指定新的起始日期，将原安排填入新计划，再进行微调。

目标：复用整份计划的训练安排，保留新计划的独立编辑与保存流程。

## 2. 已确认的需求

- 创建计划时提供“从历史计划中复制”入口。
- 可以选择一份历史计划作为来源，并选择新计划的起始日期。
- 将来源计划的安排填入新计划，避免重复配置每一天的部位、动作和目标。
- 复制后允许继续修改，再保存为新的计划。

## 3. 建议交互与日期规则

以下为最初设计建议；最终实现与验证见第6节。

1. 创建计划时可选择“空白创建”或“从历史计划中复制”。
2. 选择历史计划：显示名称、原日期范围和安排概况；已结束及已归档的计划应能作为候选，不能要求历史计划重新生效。
3. 选择新的起始日期，按原计划天数自动计算结束日期，并展示复制前后的日期范围供确认。
4. 按相对天数映射原安排：新日期 = 新起始日期 +（原日期 − 原起始日期），不依赖自然周或星期名称。
5. 点击“复制并调整”生成独立草稿，进入现有计划编辑流程，可调整名称、日期、每日部位、动作、排序、组数与每组目标。
6. 用户明确保存后，新计划才生效；取消、返回或暂存继续遵循现有草稿规则。

示例：

| 原安排 | 新安排 |
| --- | --- |
| 11月1日：胸、肩及对应动作与目标 | 11月8日：复制同样安排，允许微调 |
| 11月2日：休息 | 11月9日：仍为休息 |
| 11月7日：原计划最后一天 | 11月14日：新计划最后一天 |

默认保留相同周期长度。若用户后续修改日期范围，按现有范围调整规则处理；不自动重复填充、截断或循环铺满其他日期。

## 4. 复制内容与保护边界

- 复制每日训练 / 休息 / 未安排状态、训练部位、动作及顺序、目标组数、每组次数或时长、计量单位及左右侧口径等配置。
- 只复制训练安排，不复制已完成组数、实际训练数值、完成或撤销记录、训练时间及连续训练等统计。新计划从零记录开始，历史统计不因复制增加。
- 新计划和新计划条目使用独立身份；动作仍引用原动作库，不重复创建动作或复制整套媒体。
- 修改新计划不影响原计划、原完成记录或原归档状态；不得覆盖原计划。
- 已有未完成草稿时，沿用现有草稿保护，明确处理后才能替换，不能静默丢弃。
- 新日期范围与其他计划重叠时，按现有计划规则校验和提示，不自动合并或覆盖已有安排。
- 来源动作已停用、删除或不再适用于新安排时，应提示需要调整并保留可理解的动作信息，不静默丢项或替换成其他动作。具体允许保留与保存校验规则在实现前核对。
- 来源计划已归档或存在历史停止条目时，应明确可复用的原训练安排；不将已删除条目或旧执行状态直接恢复为新安排。实现前需结合现有归档和条目状态规则确认映射。

## 5. 验收清单

- [x] 从11月1日至7日复制，选择11月8日开始，默认结束日期为11月14日。
- [x] 每日安排按日期偏移对应，部位、动作顺序、组数、次数 / 时长和计量口径正确。
- [x] 休息日与未安排日保持区别，空白日期不会被擅自填入动作。
- [x] 支持其他周期长度及跨月、跨年、闰日的日期计算。
- [x] 复制后可微调并保存；保存前不会新增正式生效计划。
- [x] 新计划完成记录为零，历史计划与统计保持原样；新计划后续修改不影响来源。
- [x] 已归档来源、失效动作及历史停止条目有明确处理，不丢失信息或误恢复。
- [ ] 已有草稿、取消选择、返回重选、保存失败等情况不会丢草稿或生成重复正式计划。
- [ ] 后续调整日期范围、范围重叠等沿用现有规则，没有自动覆盖已有计划。
- [ ] 不改变现有单日复制、个人模板和空白创建的行为。

## 6. 实施记录（2026-11-05）

- 创建多日计划的“日期与名称”步骤新增“从历史计划中复制”。可选已归档计划，预览新旧日期范围及训练/休息/未安排天数，选择新起始日期后生成草稿。
- `FitnessPlanCopy`按相对日期复制原范围内的有效安排，计划和条目生成新ID；保留目标、顺序、计量单位和左右侧口径，排除已停止条目。完成/撤销事件、实际值、统计与媒体文件不复制。
- 使用现有草稿保护和保存入口；修改来源不发生。失效动作保留快照，在复制弹窗与编辑行提示核对、移除或重新选择。范围调整及多计划并存规则沿用现有实现，不合并或覆盖计划。
- 领域测试覆盖7天映射、休息/未安排、归档、停止条目、新ID、跨年、闰日、范围外旧日期。界面/Room集成测试覆盖真实复制入口、草稿取消/显式替换、保存前只有草稿、微调后保存、历史计划和事件不变。
