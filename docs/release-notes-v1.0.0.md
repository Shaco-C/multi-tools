# 随身工具箱 v1.0.0

首个正式版本，提供完整的离线电费分摊与账单管理能力。

## 主要功能

- 按各户电表实际用量精确分摊总电费，金额精确到分。
- 保存、修改、删除和查询历史账单。
- 自动带入上一期电表结构与读数。
- 查看本人费用趋势、月度金额、平均费用和最高费用。
- 导出 CSV，并通过 JSON 在本地备份和恢复。
- 提供清爽、暖白、纯白三种高对比度背景主题。
- 所有业务数据仅保存在设备本地，应用不申请联网权限。

## 安装

下载 `multi-tools-v1.0.0.apk`，在 Android 8.0 或更高版本设备上安装。首次从浏览器或文件管理器安装时，系统可能要求允许该来源安装应用。

SHA-256 校验值随 Release 资产一并提供。
