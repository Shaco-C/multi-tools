# 居家健身工具 · 首页、时间轴、统计与恢复建议

版本：产品评审稿 v0.2 / 2026-10-22。本文补充本轮用户需求，并与 01、04 共同定义行为。统计规则是产品口径；恢复提示是一般参考，不是测量出的生理恢复状态。

## 1. 首页布局：先看日程，再继续训练

工具内部底部导航建议使用 **今日 / 计划 / 动作库 / 统计** 四项。“管理”收进右上角，容纳我的器械、自建动作、数据备份和内容来源，避免在手机底部放过多入口。

```text
‹ 居家健身                         管理
2026年10月            [回到今天] [日历]

  胸部      腹部核心      休息      未安排
  肩部      腿部
   ●─────────○──────────○──────────○── →
  10/22     10/23       10/24       10/25
  周四·今天   周五        周六        周日
  已练3组    计划8组

┌──────────────┐ ┌──────────────┐
│ 连续训练     │ │ 今日计划部位 │
│     3 天     │ │ 胸部 · 肩部  │
│ 截至今天     │ │ 已练主部位1/2│
└──────────────┘ └──────────────┘

恢复参考                                      ›
胸部：今天已有训练记录，可查看最近记录与恢复参考。
同一肌群的较高强度训练通常需要留出恢复间隔。

10月22日 · 今天                         编辑安排
下班居家训练    当前安排已确认3/12组
[动作图] 哑铃地板卧推        2/4组
         [ 完成第3组 ]        撤销上一组
……

       今日      计划      动作库      统计
```

线框中的日期、组数和恢复时间用于解释布局，不是实际数据或训练处方。部位名称在节点上方纵向排列，日期与星期在时间轴下方，贴近用户提出的阅读方式。

恢复区默认一条摘要，不挤占训练卡；有正在进行的动作时，提供“继续训练”定位入口。详细记录和建议通过展开查看，避免每次记组都滚动很长距离。

### 1.1 日期轴必须连续

- 按自然日连续排列，不能只列有计划的日期。通常一屏展示约 5–7 天，具体随字号调整，左右滑动查看相邻日期。
- “今天”与“当前选中日期”分别标识；选中态有边框/底色与读屏说明，不能只依赖一个彩色点。
- 每日最多预览两个部位，多出的显示“+N”；点击后下方完整列出，不丢部位。实际已练部位与计划部位有文字区分。纯有氧、活动或拉伸显示相应用途标签，不强塞力量部位。
- 首次进入定位今天；顶部日历可跳到任意日期；跨月或跨年时标题更新。没有计划的远期日期也能打开并创建安排。
- 历史日可回看、明确补记；未来日只预览或编辑。点日期不会直接产生完成记录。
- 日期轴显示所有相关计划的部位并去重，下方动作仍按计划分组。计划详情中的日期轴则只表示该计划，标题明确计划名称。

### 1.2 “日程状态”和“训练事实”分开表达

| 情况 | 日期轴和选中日期的展示 |
| --- | --- |
| 有训练安排、没有记录 | 部位标签＋计划组数；今天标“待训练”，过去未完成的安排可标“未完成” |
| 有部分有效记录 | 力量显示“已练 N 组”，其他用途显示已记录段数；混合日分开显示 |
| 当前全部有效安排完成 | “当前安排已完成”；历史移除项另列，不改写原计划达成情况 |
| 无训练安排，覆盖当天的相关计划全部明确休息 | “休息”；若仍有历史记录，同时展示“有训练记录” |
| 无任何计划，或仍有未安排且无训练安排 | “未安排”，不能自动当成休息 |
| 一个计划休息，另一个有训练安排 | 日期显示训练安排；展开按计划说明各自状态 |
| 安排后来取消、改休息或归档，但已有记录 | 保留实际已练标记和历史入口；不得因安排变化显示成从未练过 |

归档计划不继续提供未来训练任务；过去的训练与安排快照仍可回看。多个计划中的同名动作只在时间轴部位标签层去重，不合并动作目标或记录按钮。

### 1.3 两张首页卡片

**左卡：连续训练。** 显示“连续训练 X 天”和“截至今天 / 截至昨天”。点击进入统计的日历记录，说明计算口径。可附小字“休息同样是计划的一部分”，不使用连续天数强迫用户每日练同一部位。

**右卡：今日计划部位。** 展示今天计划练哪些部位，并显示“已练主部位 X/Y”。完成一个有效组仅表示该部位今天练过，不表示它的全部目标已完成。多部位超出空间时显示“+N”和完整列表入口。未安排时显示“今日未安排 · 去安排”；全部休息时显示“今日休息”。存在计划外或已移除动作的历史训练时另显示“另有已练部位”，不强行纳入计划分母。

“已练主部位”按下文单一统计主归属计算，辅助参与不自动填满该卡；计划部位只是意图，不能产生训练事实。卡片详情同时列“计划部位 / 已练主部位 / 辅助参与”，解释差别。

其中 `Y=今日计划的力量部位数`，`X=这些部位与今日已练统计主部位的交集数`。纯有氧日卡片改为“今日有氧安排”，纯热身/拉伸改为“今日活动安排”，显示活动名称及段数，不显示 `0/0`，也不误报未安排。混合日附“另有有氧/活动”，展开显示“力量 N 组 / 有氧 M 段 / 活动 K 段”。

两卡始终针对今天及今天之前的记录。切到 10 月 20 日回看时，卡片不偷换成 10 月 20 日，动作区标题明确显示当前选中日期。常规字体采用接近正方形的两列卡；大字体时允许增高或单列，不能为保持正方形截断名称。

## 2. 连续训练的确切含义

一个训练日期至少有一条有效、未撤销的力量或有氧记录，即算一个训练日；不要求做完整日计划。同一天多个动作、多个计划仍只计一天。单独热身、拉伸和放松不计入此指标，但可在活动记录中查看。

所有统计、连续天数和恢复筛查使用完成记录中的**当次用途快照**；动作默认用途只负责初始赋值。力量/稳定性统一归力量口径，有氧/体能归有氧口径。首版同一计划日同一动作只有一种用途，不引入重复训练块。

| 当前情况 | 显示规则 |
| --- | --- |
| 今天已有有效训练 | 从今天向前连续计数 |
| 今天未练、昨天有训练 | 暂保留截至昨天的连续值，标“截至昨天”；今天若休息则标“今日休息” |
| 今天未练、昨天也未练 | 当前连续为 0 天；不使用负面失败提示 |
| 中间有休息或未安排且无训练记录 | 该自然日会中断字面上的连续训练 |
| 补记历史训练或撤销记录 | 根据有效训练日期重新计算 |

例：10 月 20、21 日有记录，22 日尚未训练，显示“连续 2 天 · 截至昨天”。22 日记录一组后变成 3 天；若 22 日没有记录，23 日进入显示 0 天。

如果以后增加“按计划坚持”，应作为独立指标定义计划休息日规则，不能悄悄修改“连续训练”的含义。首页可同时显示本周训练天数，弱化对连续天数的单一追求；本周卡不列入首版必需项。

## 3. 统计页

### 3.1 页面结构

```text
统计
[近7天] [近30天] [自定义]
2026.10.16 — 2026.10.22     全部计划 ▾

范围概览 · 全部用途
训练天数 4       力量完成组数 36
记录动作 9       有氧记录 2段

[部位统计] [动作统计] [每日记录]
指标：[训练天次 ▾]       用途：力量

胸部        ██████       3天次
肩部        ████         2天次
腿部        ██           1天次
……
提示：同一天可练多个部位，各部位天次不能相加成训练天数。
```

- 近 7 天包含今天及前 6 天，近 30 天包含今天及前 29 天；自定义包含首尾。统计范围截止今天，未来计划通过计划页查看。
- 默认统计所有计划中的有效历史，包括已归档计划；支持筛选一个计划。首页连续值始终按全部计划，统计页过滤后的指标明确带范围标签。
- 顶部“范围概览 · 全部用途”只跟随日期和计划筛选：训练天数仍只计力量/有氧，记录动作数包含全部用途。下方用途选择只影响榜单、榜单涉及动作数及组明细，避免顶部指标部分变化、部分不变却没有说明。
- 默认“部位统计 → 力量 → 训练天次”。有氧、热身/拉伸可切换独立列表，使用“活动天次 / 记录段数”，避免把散步一段与深蹲一组混成力量组数。
- 点击部位进入按日期列出的动作记录；点击动作统计行进入该动作的日期、组明细，并提供教学详情入口。返回保留范围、筛选和滚动位置。
- 每日记录使用日历/日期列表和组明细，能够追溯每个统计数字；空数据展示 0 和“此范围暂无训练记录”，无数据不伪造趋势。
- 采用带数值的横向条形图，排序可选数量降序或固定部位顺序。不能用饼图暗示重叠的部位天次构成互斥占比；读屏可获得相同文字数据。

### 3.2 统一指标字典

| 指标 | 定义 | 不代表什么 |
| --- | --- | --- |
| 训练天数 | 范围内存在有效力量/有氧记录的不同训练日期数 | 计划天数、完成全部计划的天数 |
| 连续训练天数 | 按第 2 节规则连续的自然日数 | 最长历史连续值、跳过休息日的坚持天数 |
| 部位训练天次 | 每个统计主部位有有效力量记录的不同训练日期数 | 点了多少次按钮、肌肉被刺激的次数 |
| 部位完成组数 | 主归属为该部位的有效力量组记录数 | 包含辅助参与的所有组数 |
| 动作训练天次 | 同一稳定动作 ID 有有效记录的不同训练日期数 | 训练场次；现有模型尚未定义场次 |
| 动作完成组数 | 该动作的有效组记录数；有氧等另称记录段数 | 该动作完成的重复次数 |
| 记录/涉及动作数 | 存在有效记录的不同动作 ID 数；顶部为全部用途，下方为当前用途 | 动作库收录数量或计划动作数量 |
| 已填写次数/时长 | 用户逐组主动补充的实际完成值之和，并显示覆盖率 | 未填写组的实际值、计划目标乘积、传感器实测 |

不能统称“练胸 18 次”而不解释。推荐显示“胸部：练了 5 天，完成 18 组”；动作显示“哑铃卧推：练了 3 天，完成 12 组”。

### 3.3 复合动作怎样归属

每个动作有一个**统计主归属**，另有可多选的主要肌肉和辅助肌肉。统计主归属只解决可相加的组数分类，不否认复合动作会练到多个部位。全身力量动作可归“全身”；无合适细分时不可随意归胸或腿。

例如卧推的统计主归属为胸部，教学仍展示肩前束、三头的参与；一组计入总力量组数一次、胸部组数一次。若展示辅助参与，必须独立标记“参与参考，可重叠”，不能叠加进主要统计。

同一天胸部、肩部都练过，各有 1 个部位天次，总训练天数仍为 1。因此：**主要部位组数可以与总力量组数对账；部位天次之和不能与总训练天数对账。**

自建力量动作必须选择一个统计主部位，并填写用途；有氧/活动/拉伸采用对应活动分类，无需随意选肌肉作为统计主归属。多选教学肌群独立保留。按记录时快照统计，后续改名、改分类、停用或合并内容不悄悄挪动旧记录。若同一动作历史上存在不同主归属，部位统计分属原快照，动作统计仍按稳定 ID 汇总并说明分类变更。

### 3.4 “具体动作做了多少次”如何支持

为兼顾一击记组与重复次数统计，建议首版提供**组明细中的可选实际值补充**：

1. “完成第 N 组”仍只确认完成一组，不弹必填次数框。
2. 明细中可填写实际次数或实际秒数，也可点“按本组目标填写”后明确保存；未操作时实际值为空。
3. 已填值称“用户填写”，支持改正和清空；清空实际值不撤销组记录。
4. 统计展示“已填写 34 次 · 覆盖 2/3 组”，不能把第三组视为 0，也不声称三组总共只做了 34 次。
5. 次数和秒数分开；单侧动作分别记录左右值，或者明确以同一值填入两侧。显示“左 36 / 右 34 次”，不默默把每侧计量翻倍。交替合计的动作按其定义统计。
6. 不把不同动作的重复次数加成健康成效，也不推算重量、热量或训练强度。重量与容量统计留待采集重量后再设计。

实际值采用正整数，低于目标仍可保存；确认一组不等于达到目标次数。没有实际完成应撤销该组，未填写则保留空值。覆盖率分母只含当前日期、计划、用途、动作和计量口径下的有效组；撤销时该组及其实际值一起退出统计。单侧只填写一边时显示“左覆盖 2/3 组、右覆盖 1/3 组”，只有两侧均填写才称完整覆盖一组。

该补充属于本轮新增设计建议，避免此前“首版不填写实际次数”导致用户要求的重复次数统计永远无数据。默认训练操作仍为一次点击。

## 4. 恢复建议：展示参考，不作恢复判定

### 4.1 依据和产品边界

Mayo Clinic 的力量训练说明建议同一肌群训练之间休息一个完整日，并避免连续两天训练同一肌群。[力量训练说明](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/strength-training/art-20046670)、[重量训练注意事项](https://www.mayoclinic.org/healthy-lifestyle/fitness/in-depth/weight-training/art-20045842)

ACSM 的公众恢复资料指出，恢复安排与训练强度、类型和持续时间有关，同一肌群的较高强度训练之间应留出至少 48 小时。该资料是一般教育参考，不能转换为所有人的固定恢复倒计时。[ACSM：A Road Map to Effective Muscle Recovery](https://www.acsm.org/docs/default-source/files-for-resource-library/a-road-map-to-effective-muscle-recovery.pdf)

因此首版采用两层信息：**最近训练记录事实＋一般恢复参考**。不为胸、腹、二头分别编造“24/36/48 小时必然恢复”的表，不显示“恢复 80%”“还差 3 小时就能安全训练”。产品没有足够的负荷、睡眠、疼痛及个体适应信息作出这种判断。

### 4.2 首页与计划编辑中的表现

| 场景 | 建议文案/行为 |
| --- | --- |
| 今天尚未记录该部位，有近期可靠记录且又有安排 | “胸部：距最近确认记录约 20 小时。今天还有胸部安排，可考虑调整部位或强度，留出恢复间隔。” |
| 只有昨日补记且没有具体时刻 | “胸部：昨天有训练记录，具体时间未填写。请结合实际训练安排恢复。” |
| 间隔已超过参考阈值 | 展示最近训练日期；不变成“已完全恢复”或保证安全的绿灯 |
| 尚无训练记录 | 展示简短通用提示；不能以“无记录”断言“没有练过” |
| 计划连续两天包含同一主要肌群 | 非阻断提醒，列出两天和重叠部位；用户可查看、换动作、改日期或保留 |
| 卧推后安排肩/三头 | 根据经过审核的参与肌群提示“近期动作也涉及该部位”；不当成额外训练组数 |
| 仅热身、拉伸记录 | 不启动力量恢复提醒；相关活动仍可在历史中查看 |

默认以最近 48 小时的力量记录作为“近期重复安排”的筛查窗口，是可解释的产品提醒阈值，不是按人算出的恢复时长。提醒文字始终注明较高强度训练的参考前提，用户可关闭同类提示；关闭提醒不改变训练历史或统计。

**同一次训练中的第 2、3、4 组不能被当成需要隔日恢复的新训练。** 今日安排提醒仅在该部位今天首条记录之前展示；开始记录后只更新事实摘要，不因每完成一组再次提示调整部位。跨日计划编辑仍可提示相邻日重叠。首版没有训练场次模型，不推断同日两个计划必然是两场独立训练。

提醒注明“仅依据已记录力量训练”。有氧/体能项目不计入力量组数，不意味着它们不需要恢复；相关页面仍可展示通用恢复参考，无提示不能解释为没有恢复需求。

恢复参考与日期切换的边界：今日首页建议面向现在和今日安排；历史页只描述当时记录与相邻安排，不用当前时钟伪造当日恢复状态。未来计划只有日期时只提示相邻日重叠，不计算精确小时。

### 4.3 时间、补记与肌群映射

- 实时确认的一组：可用确认时刻作为最近记录时刻，显示“距最近确认记录”，不宣称是整场训练结束时间。
- 历史补记：保存操作时刻和训练日期；实际训练时刻由用户可选填写，并标记“用户补充”。未填时只展示日期，不把补记操作时间当成刚练完。
- 若较近的记录只有日期，不能跳过它拿更早的精确记录计算恢复小时；降级为按日说明。
- 仅日期的相邻日记录参与“近期可能重叠”提示，不假定在午夜训练，不参与精确 48 小时计算。
- 撤销最后一条相关记录后重新找最近有效记录。更改计划、停用动作或归档计划不清空该事实。
- 肌群依据采用记录时的主要/辅助肌群快照。统计主归属、首页计划标签、恢复参与肌群各有用途，不能共用一个粗糙分类字段推断全部行为。
- 设备时间异常或实际时刻不可信时不显示负数小时，改为日期说明。恢复卡不把时区改变误算成新增训练。

## 5. 可手算核对的样例

以下均为力量训练，主归属胸/肩由内容审核确定：

| 训练日期 | 计划 | 动作与有效组 | 用户补充实际值 |
| --- | --- | --- | --- |
| 10月20日 | A | 哑铃卧推 2组 | 18次、16次 |
| 10月20日 | B | 哑铃卧推 1组；肩推 1组 | 未填写 |
| 10月21日 | A | 肩推 2组 | 未填写 |
| 10月22日 | — | 尚无记录 | — |

统计 10 月 20–22 日：训练 2 天、力量 6 组、涉及 2 个动作；胸部 1 天次/3 组，肩部 2 天次/3 组；卧推 1 天次/3 组，已填写 34 次且覆盖 2/3 组；肩推 2 天次/3 组，实际次数未知。首页显示“连续 2 天 · 截至昨天”。

撤销 21 日肩推两组后：训练 1 天、力量 4 组；肩部 1 天次/1 组；22 日当前连续为 0。撤销不删除原计划目标。把 20 日所在计划归档后，以上历史统计不变。

若 22 日 00:01 仍在 21 日页面继续记录，该组归属 21 日，22 日训练天数不会自动增加；恢复卡可以显示距这条实时记录的实际间隔。统计归属日与恢复参考时刻有意区分。

## 6. 本轮新增验收要点

1. 日期轴连续覆盖有安排、休息、未安排、无计划日期；多部位标签不漏，历史选择不改写“今日”卡片。
2. 同日多个计划在标签层去重，在执行层保持独立；休息与训练冲突可解释。
3. 近 7 天、近 30 天、自定义首尾一致；全部计划统计包含归档历史，筛选范围可见。
4. 同日同动作跨计划：训练天次去重，组数累加；复合动作主要组数不多计。
5. 连续天数、补记、撤销、跨午夜、时区变化均遵守统一规则。
6. 未填写实际次数不产生实际次数；部分填写明确覆盖率；每侧/合计/秒数不混算。
7. 恢复参考分清主要与辅助、计划与事实、精确时刻与仅日期；没有“恢复完成”结论。
8. 三主题、大字体、读屏下，时间轴、卡片、图表和计组主按钮均可理解和操作。
9. 今日同部位第 2 组不触发新的恢复安排提醒；纯有氧日首页不显示未安排；单侧只填一边时覆盖率准确。
