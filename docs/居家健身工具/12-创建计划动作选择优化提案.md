# 创建计划 · 动作选择优化提案

日期：2026-10-24。状态：用户已确认修改原型，本轮已实现核心交互并完成浏览器走查；具体范围见本文末尾和11的第8节。

## 1. 现状与问题

当前第三步把当前日的已选动作、目标输入框，以及所选全部部位和非力量用途的候选动作放在同一个长页面。候选没有独立的部位浏览层、搜索与分页机制。16条内容样稿掩盖了规模问题，扩充到常用动作库后会出现：

- 多部位候选混排，用户难以判断哪个部位已经选够、哪个仍为空。
- 填目标与找动作来回滚动，修改筛选或查看教学容易打断选择。
- 候选过多时，即使列表能够流畅渲染，用户仍需认识和比较大量动作。
- 非力量动作全部混入力量候选，用户当前的选择任务不够明确。

本轮目标是减少一次需要处理的信息，并保持“选什么—选了什么—还缺什么”清晰。

## 2. 主流程与第三步布局

保留四步主流程：名称/日期 → 每日部位 → 每日动作与目标 → 预览保存。独立动作选择页是第三步的子页面，不把创建计划扩成更多必经步骤。

第三步仅展示当前日的安排，按所选统计主部位分组：

```text
10月24日  胸部 · 肩部                  切换日期

胸部                                已选2个
  标准俯卧撑                 [组数] × [次数]
  哑铃地板卧推               [组数] × [次数]
  ＋ 添加胸部动作

肩部                                尚未选动作
  ＋ 添加肩部动作

＋ 添加热身 / 有氧 / 拉伸

当前日已选2个动作 · 肩部待补
[上一步]                         [预览计划]
```

- 已选条目保留缩略图、详情、移除和排序；动作多时每个分组可折叠。
- 填写目标与候选浏览分开；保留批量填写，可选应用到当前部位或当日全部动作，默认只填空值，覆盖已有值需明确选择范围。
- 动作数仅为数量提示，不设置没有依据的“每部位必须3个动作”或医学意义上的推荐组次。
- 每个所选力量主部位至少一个同主归属动作的已有规则保持；辅助参与不自动满足主训练部位。
- 顶部切换日期；已填写内容暂存为计划草稿，不需要为切换日期逐次点保存。

## 3. 独立动作选择页

点击“添加胸部动作”，进入标题为“10月24日 · 选择胸部动作”的页面，选择范围明确归属当前计划日。

### 3.1 缩小候选范围

- 默认限定当前部位的统计主归属、力量用途及“我的器械”；必需训练凳、固定点等仍参与完整器械匹配。
- 顶部固定搜索，支持动作名、中文别名和英文名；搜索覆盖该部位的全部可选内容，不只搜索首屏精选。
- 提供徒手、哑铃、弹力带等快捷器械筛选，以及“查看全部器械”；额外器械筛选不绕过完整器械条件。
- 所选部位作为快捷切换项显示，例如“胸部·2”“肩部·0”；切换保留当天跨部位选择。每个部位的搜索和浏览位置单独保留，搜索框显示当前实际条件。
- 热身、有氧、拉伸从独立用途入口进入；纯有氧日也能直接选择，不要求先补一个力量部位。

### 3.2 首屏与全量内容

首次进入可先显示人工维护的“常用动作”约6—8项，并提供“查看全部胸部动作（N）”。常用清单必须是当前条件下的有效内容；没有合适的精选时直接进入全部列表。它表示查找入口，不表示为个人制定训练处方。

- 已有历史后可增加“最近用过”，依据真实历史显示；不凭空生成用户偏好。
- 未收录在常用中的动作仍可通过“全部”和搜索找到。搜索无结果不能只检查常用清单。
- 全部列表按稳定规则排序，每次先显示约20项，再“加载更多”；筛选后数量、已显示数量和结束状态明确。
- 切换筛选从新结果首批开始，已勾选动作不因不在当前结果中而被取消。
- 首轮不增加胸部细分解剖、复合/孤立、难度等尚无可靠内容标签的筛选。后续有审核后的元数据再加。

### 3.3 选择与教学

- 列表保留肌肉图＋姿势图。点图片/名称查看详情，独立勾选控件负责选择。
- 底部固定“当前日已选N个 · 查看已选 · 完成选择”。数量覆盖当前日所有部位，查看已选时按部位分组；不能与整个日期范围的动作总数混淆。
- 勾选即暂存到当前计划草稿，尚未使计划生效；点击“完成选择”返回第三步填写目标。
- 返回按钮、系统返回均保留本次选择，并通过文案说明自动暂存；不把普通返回当成取消全部勾选。若提供“撤销本次选择”，必须是单独明确的操作。
- 查看已选支持明确移除。筛选看不到某个已选动作时，底部仍能找到并取消它。
- 查看教学返回选择页，保留已选、部位、器械、搜索词、已加载批次和滚动位置。

## 4. 关键边界

1. 日期上下文：选择页锁定一个计划日；完成返回后才能切换日程，防止把胸部动作加到另一天。
2. 去重：同一日同一动作ID只有一个条目；同日移除后重加，按原有规则恢复身份和已记进度。跨日允许复用，训练记录各自独立。
3. 保存范围：所有勾选、目标和顺序进入创建/编辑草稿，计划最终保存成功才改变执行中的安排。
4. 无结果：区分分类没有内容、筛选不匹配、只有缺器械动作；提供清除筛选、查看全部器械或添加自建动作入口。
5. 缺器械：明确显示缺项，用户主动确认后才加入，不自动改变器械偏好。
6. 移除部位：列出该主归属下的已选动作；用户确认后结束或移除相应安排，已有记录保持原有历史规则。
7. 单位：批量填写分别处理次数、秒数和每侧目标，不将12次转换为12秒或自动翻倍。
8. 历史编辑：未来/未开始配置与已有记录条目遵守现有快照、组数下限和身份规则；本次交互优化不改动统计口径。
9. 复制一天：继续提供独立的复制入口；只复制安排、不复制记录，有历史目标日不整日覆盖。

## 5. 建议落地顺序与验证

第一轮优先完成：第三步分组已选清单、独立选择页、部位切换、搜索、器械筛选、全量列表分批展示、固定已选入口和返回保留。常用精选只在有可靠标记时展示，不应成为选择页上线的阻塞条件。

收藏、最近用过、保存为个人训练模板放在后续迭代；按条件自动挑选仍沿用后续规划，不混入本轮手动选择优化。

下一轮原型验收场景：

- 单部位30条/80条的明确标注模拟内容中，用搜索和器械筛选定位目标，无需逐条阅读全库；模拟条目不计入正式动作库。
- 胸部勾选2个、肩部勾选1个，往返切换不丢选择；返回第三步正确分组为2＋1。
- 搜索并勾选后切换器械，已选计数保持；通过查看已选仍能移除被筛掉的动作。
- 查看动作教学后返回，位置、搜索及已加载批次保持。
- 完成选择后填写次数类和计时类目标，再去添加动作，既有目标不重置。
- 切换另一天不带入上一日的勾选状态；同一日重复选择不生成重复条目。
- 空精选、有历史、无历史、无匹配器械、纯有氧、草稿重载均可继续操作。

本轮已实现：分组已选清单、独立选择页、主部位/活动切换、搜索、器械/来源筛选、20条分批、固定已选入口、教学/系统返回保留、日期隔离及分组目标。取消末个动作保留部位意图，批量目标默认只填空值。80条模拟数据已通过浏览器实际加载和搜索验证，测试内容未加入正式内容库。
