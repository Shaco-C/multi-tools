## 2. 通用约定

- 原型顶部显示“交互原型 · 演示数据”；演示日期可切换，默认2026-10-23。它与真实记录时刻分别保存，不静默修改设备时钟。
- 底部四项：今日、计划、动作库、统计；管理在顶部。详情/表单有返回，返回来源页保留筛选、日期和位置。
- 创建和编辑使用独立草稿；未提交内容不改变执行中的安排。返回可暂存草稿，放弃有明确入口。
- 所有变更先保存再显示成功；失败保留旧数据和编辑内容。同一次请求重复提交不重复写入。
- 保存中的同一按钮暂时禁用，其他页面不得把保存结果记到新日期。弹窗不能在提交中被另一份数据覆盖。
- 表单在相关字段旁显示错误，提交后聚焦首个错误；错误不靠红色单独表达。关闭弹窗、浏览器后退与页面返回分别处理。
- 不用弹出确认打断每次计组。补记、覆盖安排、删除、恢复替换等会改变含义或丢数据的操作才预览影响。
- 小屏按手机页面布局，大屏保持内容宽度；两图与名称不可互相挤没。触控区不小于现有按钮基准，计组主按钮约56px高；网页px不宣称等于Android dp。
- 技术输入边界：计划名/动作名1—60字符；组/段数1—99；次数1—999；秒数1—3600；正整数，不接受空白、0、负数、小数、科学计数法。原型日期范围最多366天，统计自定义包含首尾且不能到未来。以上为交互保护建议，不是训练剂量，正式版上限需依据原型评审定案。
- 创建时输入空值不擅自变0；目标没有“适合所有人”的预填剂量。演示计划已有目标只用于演示；批量填写必须由用户明确执行。
- 所有“完成”都指已确认的组/段，目标次数与用户填写实际次数分开。只填一侧不等于两侧实际值完整。

## 3. 功能逐项拆解

### F01 工具入口、导航和主题

| 项 | 具体行为 |
| --- | --- |
| 入口 | 工具箱卡进入健身；原型独立运行但保留返回工具箱的层级提示 |
| 默认页 | 今日；首次无数据显示引导，已有进度提供继续入口 |
| 四页签 | 点击切页不清除记录；底部选中状态有图标与文字 |
| 管理入口 | 我的器械、我的动作、备份恢复、内容来源、主题、演示场景 |
| 返回 | 详情回来源；创建页先暂存草稿；不能一步返回导致未保存动作丢失 |
| 主题 | Fresh/Warm/White沿用现有浅色风格，切换后保留数据，图例仍可读 |
| 异常 | 本地资料不可读时不自动覆盖为空库；展示导出原始资料/重试等恢复路径 |

### F02 首页日期时间轴

- 顶部年/月、月份选择、回到今天、连续自然日轴；标签位于节点上方，日期/星期在下方。至少能看到相邻空白日。
- 每日最多预览2个部位，超出“+N”；选中后完整列出。纯有氧/热身/拉伸显示用途标签。
- 分别标识今天和当前选择；切历史日不改写今日卡。横向滚动可达前后日期，不只列计划日。
- 休息、未安排、待训练、已练、当前安排已完成、无剩余安排但有历史，均有文字。
- 多计划部位合并展示，动作按计划分组。一个计划休息、另一个训练，整体显示训练；草稿不参与。
- 过去可进入回看与明确补记；未来预览和编辑；点击日期本身不记组。月份切换和年份边界不能把同月不同年混淆。
- 无计划显示“去建计划”；未安排日显示“安排这一天”；无动作时不显示0/0或已完成。

### F03 首页双卡与继续训练

- 连续训练按全部有效力量/有氧记录的训练日期计算；今日未练可显示截至昨日；休息未记录会中断，文案中性。
- 今日计划部位固定今天；X/Y是已练主部位与计划主部位的交集，不是完成全部目标的比例。
- 计划外已练部位另列；纯有氧/活动日替换右卡标题与内容，不显示0/0。
- 长部位组合允许卡片增高；点卡可查看完整部位和口径。
- 正在训练时提供“继续训练”，定位到未完成动作或最近操作位置，不自动记组。

### F04 恢复参考

- 显示最近确认记录事实、主要/辅助参与和来源入口；只依据已记录力量训练，不能推断有氧无需恢复。
- 最近48小时仅作参考筛查；不展示恢复百分比、已恢复绿灯或强制禁止训练。
- 仅日期补记按日描述；近记录时刻未知时，不能跳过它拿旧记录算精确小时。
- 今日开始该部位前可提示近期重复安排；继续已开始的动作不每组提醒，跨午夜不凭新日期重新提醒。
- 计划编辑相邻日重叠可提示，但不自动移日/换动作；用户可查看后保留安排。
- 无记录仅展示一般说明。提醒可关闭；关闭不删除记录，不改变统计。

### F05 计划列表与生命周期

- 分为生效、草稿、归档；日期决定尚未开始/进行中/已结束，状态与完成进度分开。
- 卡片有名称、起止、训练日/休息日/未安排数、下一训练日或历史入口；不把目标组数当成实际组数。
- 新建、继续草稿、查看、编辑、复制、归档/取消归档均有明确按钮。
- 无记录计划可确认删除；有任何完成/撤销历史默认归档。彻底删除记录独立预览范围，不复用归档文案。
- 归档不出新任务、不新增组或补记，允许回看/撤销误记/改正实际值。取消归档先预览恢复的日程，不平移日期。
- 无有效安排但有历史时显示历史状态，不要求用户加假动作才能保存。

### F06 建计划第1步：基础信息

- 名称、开始日、结束日；同一天合法，包含首尾；结束早于开始或超出交互上限时阻止下一步并说明。
- 日期可选过去、今天、未来。创建过去计划不产生完成记录，未来只预览。
- 名称可按范围生成，用户手改后不被日期变化覆盖。
- 创建过程自动暂存草稿；刷新后可继续，显式保存才进入生效计划。
- 修改范围前列出将受影响日期；有历史的原日期不搬移或隐藏，无历史安排按确认结果处理。

### F07 第2步：每日部位与休息

- 范围内逐日可选：训练/休息/未安排。默认未安排，不能默认全休息。
- 力量训练日多选主部位；纯有氧/活动可不选肌肉。所选部位只是安排意图。
- 批量应用到日期先选择目标日并预览，不覆盖有历史日。取消某部位先显示受影响动作。
- 首次生效保存至少一个完整训练日；训练日缺动作/目标需补齐或明确改未安排；草稿可不完整。
- 复制日程只复制目标，记录从0开始；目标日含撤销历史也不整日覆盖。

### F08 第3步：动作选择与目标

- 已实现结构：第三步按部位分组管理已选和目标，候选由“添加该部位动作”进入独立选择页。日期固定，主部位/活动快捷切换、搜索、器械/来源筛选、每批20条及固定查看已选。
- 返回清单和系统返回保留选择；详情返回保留搜索、筛选、已加载批次和滚动位置；被筛掉的已选仍可单独查看和移除。取消最后一个动作不自动取消原部位。
- 批量目标可按部位或当天全部应用，默认只填空值，覆盖已有值需明确勾选；暂存失败显示当前选择仍在内存，重试成功才标为已暂存。

- 候选默认按所选统计主部位及我的器械匹配；查看全部仍能打开不匹配条目，标明缺失器械。
- 双图/名称点开教学，勾选框选动作；查看详情返回后选择不丢。多部位结果同ID去重。
- 每个计划日同一动作只一个条目、一种用途；不同计划允许重复，进度独立。
- 必填组数与每组次数/秒数；每侧口径写完整。批量目标不能把次数直接套到秒数动作。
- 有明确上下移按钮排序，不依赖拖动；顺序不改变记录身份。
- 每个所选力量主部位至少有一个同主部位动作；缺口可补动作或取消空部位。辅助参与不自动满足该部位。
- 仅当内容允许时选择用途，保存本次用途；有历史后不可直接切换用途/计量。

### F09 第4步：预览、保存与日程编辑

- 显示每个日期、部位、动作目标、必需器械及未安排/休息；可以回到具体日期修改，前面填写保留。
- 保存阻止重复提交；成功后到计划详情/今日，选择日期明确；失败保留草稿。
- 未开始动作可替换/移除；有历史时移除仅结束剩余安排，历史保留。
- 移除再加入同一动作ID，恢复原条目及进度。名称相同但ID不同的自建动作不合并。
- 已完成2组不能把目标改为1；修改每组目标只影响后续组，已记录快照不变。
- 全部剩余安排结束后显示无剩余安排及历史，不把删除动作当作达成原计划。

### F10 动作库分类、搜索与筛选

- 十个主要肌群入口及全身、有氧、活动/拉伸入口；分类肌肉图和文字共存。
- 首页仅显示分类；点分类进入独立动作列表，再点动作进入详情。搜索/筛选/双图列表放在分类内，返回分类不混入动作列表。
- 搜索只作用于当前分类；清空筛选不清空分类归属；从详情返回保留筛选及滚动位置。分类数量显示不受器械筛选的相关动作数，列表显示当前匹配数/分类总数。
- 自由浏览可按主要/辅助肌群找动作；计划选择按统计主部位，界面说明语境。
- 搜中文、英文、别名；空白搜索恢复列表；飞鸟与反向飞鸟用完整名区分。
- 过滤器包含部位、用途、器械匹配、内置/自建、审核过的难度；未知难度不冒充入门。
- 原型明确是16个内容样本，不把250候选当成250个已具备教学的动作。
- 列表同时显示肌肉示意和姿势图；无结果显示清空筛选/查看全部；自建无图与素材加载失败各有不同说明。
- 分类数量按当前可浏览的唯一动作计算，不把同一复合动作重复计入全库总数。

### F11 动作详情与媒体

- 名称/别名、器械、用途/计量、介绍、肌群示意、准备/过程/还原、易错点、可用替代、来源及版本。
- 教学图片左右滑动切换/放大，不再要求点击起始/结束姿势按钮；显示当前姿势名称、步骤号和圆点页码。电脑可拖动或用左右/Home/End键，禁止自动翻页；首末图不循环。
- 切换图片不改变训练进度，横向滑动不阻止页面纵向浏览；静态保持类显示起始/保持标签，个人单图不显示多图提示。放大后仍可滑动，关闭保留当前帧；返回列表后再次进入动作默认第一帧。
- 双帧源图按独立帧等比裁切，不能把相邻姿势露在当前图中。无GIF不出现空播放器；图文脚本按具体变式对齐。
- 已有GIF才提供暂停/播放；静态帧不能伪装连续教学；列表不播放所有动画。
- 从训练进入：主CTA返回训练，不加入第二份动作；从选择进入：加入所选日期；自由库进入：选计划和日期。
- 已达目标、历史日、未来日、归档计划上下文都带回，不能返回时变今天。
- 图片缺失保留名称与文字并提示，不能加载另一个动作的图；待审小样有状态说明，不能标记教学审核通过。

### F12 一击记组/段

- 展示目标、有效已完成数、剩余、最近确认时间；少量组用圆点辅助，多组仍以数字为准。
- 主按钮“完成第N组/段”独立，图片进入教学；达到目标禁用新增，撤销或明确提高目标后才可继续。
- 保存携带发起时计划ID、日期、条目ID和操作ID；切页、慢响应、重试不能改归属或重复计组。
- 一次点击不推断次数、秒数、重量、热量；计时动作明确“完成后手动记录”。
- 随时切动作，无需强制开始/结束一场；跨午夜可继续原训练日期，并显示切到今天入口。
- 重新进入默认今天；昨天进度仍能回看；归档和未来日无新增按钮。

### F13 撤销与实际值补充

- 永久保留“撤销上一组/段”，不只依赖短暂提示；撤销针对最近有效事件，反复提交同操作只撤一次。
- 撤销后再次完成是新事件，旧撤销保留；组序号不是事件身份。
- 组明细显示当时目标、记录时间、训练日期、补记标记和可选实际值。
- 支持按目标填写、手动填写、改正、清空；只有明确保存才进入次数/时长统计。
- 普通实际值正整数或空；每侧分别左右，明确同值填两侧；只填左侧时右侧未知，覆盖率分开。
- 实际值低于目标可保存；清空实际值不撤销组。撤销后实际值随该事件退出统计。

### F14 历史回看与补记

- 通过时间轴、计划日期、统计明细进入；标题带年份/日期，明显区分今天。
- 过去未达目标的生效安排可明确补记，确认训练日期；实际时刻可选，操作时刻保留真实值。
- 实际时刻必须落在声明的实际训练日期/时区内并且不晚于当前时刻；不能用补记提交时间冒充过去。
- 无安排先创建/完善当日安排再补记；未来禁止补记，归档需先取消归档。
- 补记或撤销后同步更新首页、连续天数、部位/动作统计。仅日期记录恢复提示降级。
- 日期范围缩短、动作停用、计划归档不隐藏已记录的原日期历史。

### F15 统计范围、榜单与明细

- 近7天/30天包含今天，自定义首尾包含、结束不晚于今天；起止展示完整年份。
- 顶部范围概览按日期＋计划筛选，标全部用途；下方用途筛选只影响榜单及明细。
- 默认部位/力量/训练天次；支持动作统计、每日记录及组数指标；有氧/活动按段，不混成力量组数。
- 训练日：有效力量/有氧组至少一条的不同日期；同日多计划只一天。部位和动作天次各按日去重。
- 力量组按事件主归属，只计一次；部位天次之和可超过总训练天数，图例说明原因。
- 实际次数/时长只加已填值并显示覆盖率；不同单位/每侧口径分开。动作默认分类更新不重写历史快照。
- 默认包含归档历史；彻底删除记录才影响统计。空数据有明确0与空态，不绘虚假增长线。
- 点击条形/行进入组成数字的日期与事件，再可查看教学；返回保留范围和筛选。

### F16 自建动作与个人图片

- 新建字段：名称、用途、计量/左右口径、必需器械、统计归属；力量必选主部位与教学肌群，其他用途可不标肌群。
- 可补别名、简介、准备/过程/还原、图片；缺图明确个人占位仍可用于计划，不降低内置库发布门槛。
- 复制内置为我的动作创建新ID，保留复制来源；不覆写内置条目。相同名字需提醒但不凭名字合并历史。
- 图片上传显示预览，可替换/取消；解码失败或过大说明错误，不保存悬空引用。原型图片按本地演示资料处理。
- 改名不改ID；已有历史的用途/计量变更不得改写原条目快照。停用退出新选择，历史仍可显示。
- 停用前列出未开始计划中的引用，提示替换或保留；内置内容下架与个人停用区别说明。

### F17 我的器械

- 徒手、哑铃、弹力带为场景初始偏好；哑铃数量、长/短弹力带、训练凳、单杠、固定点单独说明。
- 必需条件按全部满足匹配；器械有替代组合时每个组合内部AND、组合之间OR，不能把“哑铃或训练凳”误当可用。
- 改器械只影响新动作筛选，不删除已有安排；计划所需器械与当前偏好不符时展示提示。
- H/A/G是候选场景标签，不直接等于可用性或难度；用户可查看全部，但加入缺器械动作前有明确信息。

### F18 备份导出与恢复

- 入口在管理；导出明确范围为健身数据、个人动作/图片、偏好、快照和完成/撤销；不包含其他工具。
- 首版正式建议媒体包，与只含JSON的既有接口区分；原型若使用演示JSON必须写出演示格式，不能声称已验证APK恢复。
- 选择文件 → 预检版本/结构/引用/媒体完整性 → 展示数量和替换范围 → 用户确认 → 恢复 → 汇总。
- 预检失败不出现恢复按钮；取消或失败保留原资料。恢复中禁用相关写入，成功后统计重算。
- 缺内置内容保留快照并提示教学不可用；缺用户图片、损坏或版本不支持，不假装完整恢复。
- 覆盖前建议导出当前资料；彻底删除资料独立确认。不能默认把受限第三方媒体一起导出。

### F19 内容来源、缺失与版本

- 来源页可离线显示作者/许可/原链接/修改和审核状态，原链接只是追溯，不是训练时依赖。
- 稳定ID关联内容版本；无法显示旧媒体时保留必要文字，不换成相似动作蒙混。
- 生成图或初稿的来源标记为原创/生成及待审状态；未经专业审校不标“标准动作已认证”。
- 不用“候选250”当“已发布250”；全部候选与当前16样本状态分开。

### F20 失败、演示重置与可访问性

- 原型提供独立演示面板：无计划、纯有氧、仅热身、归档、保存失败、补记、跨日等可复现状态，不塞进普通训练流程。
- 演示重置要确认并明确只影响本地原型资料；刷新不默认重置。
- 本地存储写入失败不更新计数，保留重试。备份导入不能执行源内容脚本。
- 弹窗有标题、关闭、焦点与键盘操作；无障碍名称说明肌肉图/姿势图，图表数据有文字。
- 手机布局、大字体、横屏、桌面宽度和三主题分别检查；视觉检查不代替数据规则验证。

## 4. 交互必须保持的状态

| 从哪里离开 | 返回后保持 | 允许重置的条件 |
| --- | --- | --- |
| 选择动作 → 详情 | 已选、搜索、筛选、所选计划日 | 用户明确清空或提交 |
| 训练 → 详情 | 计划/日期、进度、滚动位置 | 用户切日；重新进入工具默认今天但旧记录保留 |
| 统计 → 动作明细 → 教学 | 日期范围、计划/用途/指标、滚动 | 用户改筛选 |
| 新建计划各步骤 | 名称、范围、每日部位、动作、目标 | 明确放弃草稿 |
| 自建动作 → 选图片 | 表单与已有图片，取消选择不丢字段 | 明确放弃 |
| 恢复预检 → 取消 | 原本数据库、图片、偏好、统计 | 只有确认且成功后替换 |

## 5. 首版与后续的分界

原型覆盖本表首版核心流程。随机推荐、倒计时/通知、重量/容量、收藏、周模板、无计划临时训练快捷入口、云同步、摄像头识别继续留后续，不用一个无作用按钮制造已覆盖的印象。

没有专业审核人时仍可完成内容结构、制作样稿和交互验证，但16样本保持待审；这项缺口影响正式教学发布，不阻止继续做本地原型。

## 6. 制作前自检

- F01—F20都有页面或行为落点，主要按钮有真实去向；不能只有正常页面没有异常状态。
- 同一份动作、计划和事件数据驱动所有页面；展示层不能另写一份假进度。
- 首次使用、用户两日示例、纯有氧、仅热身、每侧时长、多计划、移除重加、归档/恢复、补记与跨日都准备样例。
- 原型验收记录列出已实现/模拟/未实现；模拟备份和浏览器存储不替代Android文件与Room验证。
