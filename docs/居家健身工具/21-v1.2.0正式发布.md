# v1.2.0正式发布

日期：2026-10-25。用户确认当前初版并要求推送main、建立tag、提供正式APK及中英文README。本次正式版纳入居家健身，保留独立测试包。

## 发布内容与开关

- 正式版`com.pockettoolbox`，`1.2.0` / versionCode `3`，沿用原正式签名；Debug为`com.pockettoolbox.debug` / `1.2.0-debug`。
- 首页正式开放健身入口，Release与Debug均携带876个来源动作、1746张来源原图及16份中文样稿。计组、计划、统计、个人动作与带图ZIP恢复与已验收初版一致。
- `content/fitness/android/release.properties`独立记录产品发布开关及锁定的内容版本、来源revision和原包哈希。Release预构建核对这些值，来源ZIP由既有SHA-256校验任务验证。
- 产品发布与专业审校分别记录。`content.properties`的`releaseApproved=false`、`reviewedCount=0`保持实际审校状态；首页标注含英文来源动作，详情和管理页继续说明原文与审校状态。没有把发布认可写成专业教学审核通过。
- `build-native-content.mjs`继续只生成内容目录，不覆盖独立发布配置。将来变更来源版本时，需要同步核对发布配置。
- `README.md`为中文，`README.en.md`为英文，顶部互相切换；说明功能、截图、安装、三个工具的备份、构建与来源。应用界面当前仍为中文。

## 发布校验

验证结果：

- Debug主机测试共191项通过：公共模块5、电费51、饮食29、健身106，0失败、0错误、0跳过。新增发布开关测试防止正式版入口被关闭，且不会把专业审校状态误标为通过。
- Release变体另执行7项针对性测试，全部通过：发布入口和审校状态、打包内容状态、876条来源全部可用于计划、未知器械处理、全部图片解码、全部SVG渲染、来源动作的备份恢复。
- Debug / Release构建成功；两种App Lint均为0错误、17警告，主要为依赖版本与目标API建议，另有图标及简化代码建议。未为本次发布改动依赖版本。
- 对Debug与Release最终APK均逐一验证1762条图片路径、1746张来源图SHA-256、17份SVG及来源授权文件。内容目录和原包SHA-256检查通过。
- AAPT核对正式包名`com.pockettoolbox`、版本`1.2.0` / `3`、名称“随身工具箱”、minSdk26、targetSdk36，正式包无调试标记、无联网权限。独立测试包继续使用`.debug`包名。
- apksigner验证正式APK签名有效、使用既有证书，可用于升级旧正式版。
- 双语README本地文件与图片链接已检查。SDK、Gradle缓存及构建临时文件均在D盘。

本机日志为`outputs/release-v1.2.0-build.log`及`outputs/release-v1.2.0-release-tests.log`。最终文件为`outputs/multi-tools-v1.2.0.apk`及同名`.sha256`，安装包与校验文件作为[GitHub Release附件](https://github.com/Shaco-C/multi-tools/releases/tag/v1.2.0)分发，不放入Git源码历史；校验值以附件为准。

```powershell

```
