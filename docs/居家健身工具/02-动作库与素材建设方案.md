# 居家健身工具 · 动作库与素材建设方案

状态：内容建设设计与来源调研，2026-10-22。本文不表示素材已下载、版权已逐项核实或教学已审校通过。

## 1. 把“大多数常用动作”变成可验收范围

用户需要尽量开箱即用。当前已扩充为 250 个去重后的动作候选，再按审核结果确定正式库；先覆盖徒手、哑铃和弹力带，兼顾常见健身房器械，并补充活动拉伸与有氧。候选清单见 [03-首批动作候选清单](03-首批动作候选清单.md)。具体获取路径、底图来源和试采样流程见 [05-动作素材获取与生产流程](05-动作素材获取与生产流程.md)。

动作数量不是唯一指标。每个部位都检查“可在现有器械条件下实际完成的常用动作”，以及起止图、计量和说明的完整度。不存在合理徒手替代的部位，可以如实提示器械需求，不能为了填满矩阵虚构动作。

去重原则：

- 中文名、英文名、常见别名指向同一动作 ID，例如“哑铃侧平举”和俗称不应重复计数。
- 器械、支撑方式或运动路径明显不同的常用变式可以独立收录，并关联同一动作家族。
- 动作可出现于多个部位筛选结果，但全库数量按唯一 ID 统计。
- “飞鸟”必须拆清胸部飞鸟与肩后束反向飞鸟；不能只根据名称中的一个词映射肌群。
- 素材不全、授权不明或未通过教学审校的候选不计入正式可用数量。

## 2. 部位、肌肉与器械的分类

下面是编辑分类提案，不是精确生理贡献比例。动作的具体主要/辅助肌肉必须在条目审校时确认。ACE 的官方动作库也采用身体部位、器械和经验等级组织内容，可作为分类参考；本项目分类另行整理。[ACE 动作库](https://www.acefitness.org/resources/everyone/exercise-library/)

| 用户看到的部位 | 肌肉图需要能表达的区域 | 优先视角 |
| --- | --- | --- |
| 胸部 | 胸大肌区域；细分部位按条目依据标注 | 正面 |
| 背部 | 背阔肌、上背相关区域、竖脊肌区域 | 背面 |
| 肩部 | 三角肌前束、中束、后束；肩袖按需要另标 | 正面＋背面 |
| 肱二头肌 | 上臂前侧，必要时区分肱肌参与 | 正面 |
| 肱三头肌 | 上臂后侧 | 背面 |
| 前臂 | 前臂屈肌、伸肌相关区域 | 正面＋背面 |
| 腹部与核心 | 腹直肌、腹斜肌等；深层稳定肌采用标签说明 | 正面，必要时背面 |
| 臀部 | 臀大肌、臀中肌等区域 | 背面＋侧面辅助 |
| 腿部 | 股四头肌、腘绳肌、内收肌等 | 正面＋背面 |
| 小腿 | 腓肠肌、比目鱼肌等区域 | 背面，必要时正面 |

补充分类“全身”“有氧”“热身与活动”用于组织动作目的，不能把它们当成具体肌肉名称。

器械条件采用“全部必需条件”与“可选条件”分开表达。例如平板哑铃飞鸟需要哑铃和合适训练凳，站姿弹力带划船可能需要可靠固定点。不能把全部器械标签解释为任意满足一个即可。

“次 / 秒”“双侧整体 / 每侧 / 交替合计”的计量口径独立于部位分类。交替动作必须明确一次指一侧动作还是左右一轮；个人计划中显示完整口径。

## 3. 一条正式内置动作需要哪些内容

| 内容 | 要求 |
| --- | --- |
| 身份 | 稳定 ID、中文标准名、英文名、别名、动作家族、内容版本 |
| 分类 | 主展示分类、用途（力量/有氧/热身/拉伸）、单一统计主归属、主要肌肉、辅助肌肉、器械必需条件、动作类型、难度依据 |
| 计量 | 次或秒；每侧或合计；完成一组的含义 |
| 简介 | 简短说明动作目的与形式，避免夸大训练效果 |
| 教学 | 准备姿势、运动过程、结束/还原，按顺序分步 |
| 提示 | 常见错误、关键动作提示、器械布置要点；只写与该动作相关的内容 |
| 肌肉图 | 正确的底图区域映射，主要与辅助的图例和文字标签 |
| 姿势图 | 列表缩略图，能够在小尺寸下辨认动作 |
| 步骤图 | 动态动作至少能清楚分辨起始和结束，通常 2–4 张；复杂过程按需要补帧 |
| 静态动作 | 进入姿势、保持位置与关键点、退出说明，不强行为其制造动态重复 |
| 动图 | 可选，需能验证运动路径，支持暂停；仍保留静态关键帧 |
| 来源 | 内容作者、参考页面、媒体来源、许可及修改说明 |
| 审核 | 文案审校、动作审校、肌群映射核验、媒体完整性、离线可用性 |

运动注意事项采用短句放在动作详情的相关步骤附近。出现疼痛或异常不适时应停止动作，不使用“忍痛坚持”“保证不伤”等表述。产品不诊断用户，也不根据单一部位名称自动给出个体训练剂量。

### 条目样例：前臂平板支撑（文案结构示例）

- 名称：前臂平板支撑；常见别名：平板支撑。
- 器械：地面，垫子可选；计量：秒，一次保持结束后确认一组。
- 简介：以前臂和脚部支撑身体，练习保持躯干稳定。
- 图 1：准备支撑的位置；图 2：身体保持状态与姿势要点；图 3：控制结束支撑。
- 文字要点：肘部与肩部位置对应，躯干保持稳定，避免塌腰或把臀部抬得过高，保持呼吸。
- 详情肌肉图：经审校后标注主要及辅助区域，不能根据编辑者印象随意涂色。

上述短文按官方教学信息归纳，用于说明条目结构；正式发布前仍需动作审校和独立图片制作。没有复制或下载 ACE 图片。[ACE：Front Plank](https://www.acefitness.org/resources/everyone/exercise-library/32/front-plank/)

## 5. 推荐的制作路线

先保留两个候选方案，通过小样决定比例：

- **开放内容与原创制作组合**：筛选可追溯的动作资料，形成中文编辑稿；选择许可清楚且动作准确的姿势图，缺失部分原创制作；人体肌肉图统一建设。
- **商业动图库组合**：若付费素材能满足大部分动作及分发要求，用其提供连续教学；统一补充中文介绍和肌肉图。只在样例与购买条件确认后进入采购。

不把直接抓取、批量生成、购买素材中任一种方案预先视为全部问题的答案。关键是动作正确、图文匹配、来源可用、用户离线能看清。

### 肌肉图的统一制作

使用经过核验的人体正面/背面底图，维护肌群区域与标签。分类页只高亮该分类区域；动作页由主要/辅助肌肉映射生成图。

底图建议采用可编辑矢量母版，成品按 Android 运行时需要输出矢量或压缩图片。同一底图和肌群映射可复用，避免每个动作都重新画出不同人体。深层肌肉无法从表面准确表现时，用独立局部示意或文字说明，不伪造透视细节。

本轮已找到 Wikimedia 上 Termininja 制作的正面与背面肌肉 SVG，文件页标注 CC BY-SA 3.0，可作为底图候选。wger 也引用这些来源，但其各个高亮图层的覆盖和改作链尚未逐项核验。原图许可、图层设计、署名与实际使用方式详见 [05 第 4 节](05-动作素材获取与生产流程.md)；本次没有制作或发布底图成品。[正面文件页](https://commons.wikimedia.org/wiki/File:Muscular_system.svg)、[背面文件页](https://commons.wikimedia.org/wiki/File:Muscular_system-back.svg)

### 原创/AI 辅助姿势图

先完成动作脚本，再制作图片：同一成年示范体型、统一服装、器械、视角、背景、关节和接触位置，保持跨帧一致。动作审核人员先确认每个关键帧应表现什么。

生成图片需要逐帧核对肢体结构、支撑点、器械握法、运动方向以及图文对应。不能仅凭画面美观就当作标准教学，也不能把不连续或结构变化的图串成“正确动作动画”。存在禁止 AI 衍生条款的第三方图不得作为生成参考。

类别肌肉图与动作姿势图可保持共同的中性教学风格，但教学姿势必须以准确性优先。封面、装饰与教学素材采用不同审核标准。

## 6. 先验证 12 个代表动作

小样建议：标准俯卧撑、哑铃地板卧推、平板哑铃飞鸟、单臂哑铃划船、哑铃侧平举、哑铃弯举、弹力带三头下压、徒手深蹲、哑铃罗马尼亚硬拉、臀桥、前臂平板支撑、站姿提踵。

这批动作同时覆盖地面/站姿、单侧/双侧、次数/秒数、正面/背面肌群、额外训练凳和固定点要求。它不是给用户安排的一套训练，也不要求全部在一天完成。

2026-10-23 复核补充：保留这12个核心样例，另加单手哑铃手提箱静止持握、原地踏步、毛毛虫爬行、半跪姿髋屈肌拉伸4个边界样例，补齐前臂/每侧计时及有氧、热身、拉伸用途。合计16个样例均取自现有250候选，不增加全库数量；具体检查项见 [05 第5节](05-动作素材获取与生产流程.md) 和 [08](08-设计复核与下一阶段计划.md)。

每个样例形成完整内容包：中文说明、肌群映射、列表双图、2–4 个关键帧或静态姿势分解、来源与许可记录。至少选一个合适动作验证动图增强效果。

小样评审同时检查：手机列表双图是否看清；大图是否能区分起止；文字是否过长；左右口径是否一致；主题切换后是否可读；打包后体积、解码内存和滚动表现。通过后再扩大批量。

## 7. 文案与素材处理流程

```mermaid
flowchart LR
    A[候选动作] --> B[去重与名称规范]
    B --> C[来源与许可核对]
    C --> D[中文编辑与肌群映射]
    D --> E[素材采用或原创制作]
    E --> F[动作及图文审校]
    F --> G[压缩与离线检查]
    G --> H[发布内容包]
```

每一步保留状态与原因。素材未通过时只回退该条目，不通过隐藏错误来凑动作数量。最终审核失败的条目替换或延后，并在发布清单中说明覆盖缺口。

逐资源台账至少保留：资源 ID、关联动作 ID、类型、作者、原页面与文件 URL、许可证名称与 URL、获取日期、源版本、是否修改及说明、本地路径、校验值、中文审校与动作审校状态。

翻译、裁切、改色、格式转换也应保留修改记录。中文改写不能自动消除源内容的许可义务；对允许修改并要求相同方式共享的内容按具体条件处理。[CC BY-SA 4.0 官方说明](https://creativecommons.org/licenses/by-sa/4.0/)

## 9. 包体积与离线体验

- 正式内容必须随应用或明确的本地内容包可离线使用；首版优先随应用内置，不依赖训练时下载。
- 缩略图按显示尺寸制作；姿势封面尽量复用步骤图，人体底图按肌群映射复用。
- 静态图可评估 WebP；动图格式选择以 Android 8+ 的实际解码与包体测量为准，不能只按扩展名判断。
- 动作列表只加载缩略图，详情只保留当前动作所需媒体；不能一次把全库动画解码到内存。
- 示例估算：250 动作、每个 3 张平均 100KB 的步骤图约为 75MB；20 个平均 1.5MB 的动图另增约 30MB。此为十进制设计估算，未计元数据、其他图片及安装开销，也不是 APK 实测结果。
- 小样阶段测量实际包体积后，再决定全库图像尺寸、动图覆盖数量和是否需要后续可选内容包。

## 10. 内容发布验收

每个正式内置动作都应满足：中文名清晰且别名可搜；器械条件完整；计量与左右口径明确；主要/辅助肌群可解释；列表双图可辨认；步骤图与文字对应；媒体可离线打开；来源与许可可追溯；教学审校已完成。

首版接受部分动作没有 GIF，不接受用损坏链接、空占位图或未经审校的生成图补足发布数量。实际有效动作数、各部位器械覆盖和仍缺内容，在发布前单独列出。
