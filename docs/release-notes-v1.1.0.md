# 随身工具箱 v1.1.0

在原有电费工具之外，新增离线“饮食不适记录”。从工具箱首页打开即可使用，与电费账单分别保存和备份。

## 新增功能

- 只记录出现不适的饮食，不要求登记正常饮食。
- 品牌、品牌下的食品与不适类型统一维护，记录时直接选择。默认不适类型为腹泻，也可修改默认类型。
- 进食时间只记日期；每次不适自动记录日期与时分，可手动修正。一次饮食支持多次不适。
- 品牌和食品明细、时间线、带数字的品牌横向柱状图；支持不适次数 / 关联饮食次数切换，类型及近 30 / 90 天筛选。
- 保存 / 删除后可撤销；饮食可结束和恢复，食品 / 品牌 / 类型可停用和重新启用，保留历史。
- 独立 JSON 备份与校验后恢复，CSV 导出包含每次不适时间、时区和备注。
- 支持首页现有三种浅色背景主题。

## 安装与数据

- Android 8.0（API 26）及以上，包名仍为 `com.pockettoolbox`。
- 版本号 1.1.0，versionCode 2，沿用 v1.0.0 正式发布密钥，可覆盖升级正式版。
- 新工具首次打开不含示例饮食。先到“管理”添加品牌和食品；原有电费数据库不进行结构变更。
- 应用不新增联网或存储权限，导出由系统文件选择器完成。备份是明文文件；换机前分别导出电费与饮食备份。
- 本版 APK 为本地交付包，GitHub Release 发布状态以仓库 Release 页面为准。

统计描述个人记录过的餐后不适关联，不判断原因，不计算发生率，也不表示未记录食品安全。
